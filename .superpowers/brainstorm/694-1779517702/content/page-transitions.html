页面切换动画 — 三种风格

路由跳转时的过渡效果，影响全局体验。之前 Transitions 已移除，现在用 GSAP 重新设计

A

淡入淡出 + 微位移

离开页面 opacity → 0 + translateY(-8px)，进入页面 opacity → 1 + translateY(0)。简洁流畅，类似 iOS 导航过渡。约 350ms

B

方向性滑动

根据导航方向决定动画：← 返回时右滑出、→ 前进时左滑入。列表→详情向上展开，详情→列表向下收回。有明确的空间感。约 400ms

C

缩放+淡变

新页面从 0.95 scale 放大到 1，同时 opacity 淡入。旧页面缩小到 1.02 + 淡出。有「深入」或「回到」的层级感。约 400ms
