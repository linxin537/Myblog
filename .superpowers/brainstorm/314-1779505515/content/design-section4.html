🔧 新增工具模块

identicon.ts — 头像生成器

  • hash(username) → 确定性几何头像
  • 5×5 网格对称图案 (GitHub style)
  • 12 色调色板
  • 输出 SVG Data URI
  • 支持自定义上传覆盖

covers.ts — 封面映射表

  • tag → { gradient, icon, iconSize }
  • 图标占比 ~30%（更和谐比例）
  • 预置 ~15 种标签风格
  • 未匹配标签用通用默认图
  • 输出 CSS gradient string
